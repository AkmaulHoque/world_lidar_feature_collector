# GitHub Upload Guide

Repository: https://github.com/AkmaulHoque/world_lidar_feature_collector

1. Extract this archive.
2. Upload the contents of this folder to the repository root.
3. Do not upload `__pycache__`, `.pyc`, or `.pyo` files.
4. Commit with: `Release LiDAR AutoVector Studio v0.6.1`.
5. Create tag/release `v0.6.1` and attach the ZIP from the `release` folder.
6. Upload that same release ZIP as a new version in the QGIS Plugin Repository.
